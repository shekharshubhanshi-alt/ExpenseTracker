# Expense Tracker with Analytics Dashboard

A full-stack web application for tracking, managing, and analyzing personal expenses.

The application provides a structured way to record expenses, organize them by category, monitor spending against a budget, and view monthly spending insights through an analytics dashboard.

---

## Features

- Add new expenses
- Edit existing expenses
- Delete expenses
- Category-wise expense tracking
- Monthly spending analysis
- Budget monitoring
- Expense analytics dashboard
- MySQL database integration
- RESTful backend API
- React-based frontend
- Separate frontend and backend architecture
